# Agent 开发文档索引

## 定位

`agent-docs/` 是仓库内部的开发知识层，面向修改代码和自动化的 Agent。这里不写最终用户教程，也不加入 `docs/SUMMARY.md`。公开行为仍应同步到 `README.md` 或 `docs/`；本目录只解释如何安全地找到、修改和验证实现。

## 文档层级

1. 根 `AGENTS.md`：全仓库必须遵守的约束、事实源和路由。
2. 最近的目录级 `AGENTS.md`：目标模块独有的入口、不变量、依赖和验证。
3. 本目录主题文档：跨多个目录但只维护一份的架构与工作流知识。
4. 源码、构建文件、启用的 CI：最终实现事实；发现文档漂移时修正文档，不让旧文档覆盖代码事实。

## 维护原则

- 每条知识只有一个权威位置。目录级文件只写局部差异，通过链接引用主题文档。
- 记录稳定的接口、不变量和验证口径，不记录一次性调试过程、临时路径或个人环境快照。
- 事实与推断分开。工具/CI/依赖版本可能漂移时，以当前文件和现场检测为准。
- 新增普通实现文件无需登记；新增入口、目录、依赖、生成关系或核心调用链时才更新文档。
- 内部流程不得复制到 `docs/` 的最终用户正文；用户可感知的接口变化则必须同步公开文档。

## 文档变更自检

- 所有相对路径存在。
- 根目录表、最近的 `AGENTS.md` 与实际结构一致。
- 命令区分了“示例”“本机已执行”“CI 已执行”。
- 没有把 configure、compile、static check、runtime check 混称为“测试通过”。
- 没有要求编辑 `docs-repo/`、build 目录、Git 子模块生成物或其他非权威副本。
